Data meaning and compatibility

Loads use exercise-aware descriptors (additional bodyweight load, dumbbell per hand, kettlebell weight, etc.). Legacy ambiguous load types remain intact and flagged rather than reclassified. Default values are not falsely treated as completed. Cardio distance, ascent, Echo calories and device calories are separate fields. Every workout carries its Track A version and prescription ID. Exports use the travel logger schema and require an import mapping for the existing Raspberry Pi database; they are not drop-in database replacements.
